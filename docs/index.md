# Roles API для фронтенда

Сервис хранит роли, шаблоны ролей и назначения пользователей в пределах `system`, `workspace` или `project`.

| Задача | Документация |
| --- | --- |
| Создать роль и назначить её пользователю | [Быстрый старт](quick-start.md) |
| Сделать форму, список и обработку конфликтов | [Интеграция фронтенда](guides/frontend.md) |
| Разобраться с аутентификацией и CORS | [Ограничения](limitations.md) |
| Изучить хранение и транзакции | [Устройство сервиса](role-module.md) |
| Посмотреть результат архитектурной проверки | [Проверка архитектуры](architecture-review.md) |

Источник HTTP-контракта — `api/server/roles/openapi.yaml`. Примеры ниже используют условные ID: подставляйте значения своего окружения и ID из ответов API.

Роль относится к одному `scope` — паре `type` и `id`. Назначение связывает пользователя с ролью. Шаблон хранит заготовку имени и прав, чтобы заполнить форму создания роли; постоянной связи роли с шаблоном нет.
