# Ограничения интеграции

- Аутентификация отключена. Обязательная переменная `DEV_ACTOR_ID` задаёт backend-процессу автора всех операций. Без корректного значения сервис не запускается.
- Конкретный JWT, cookie или OAuth-контракт не реализован. Передача `Authorization` сама по себе не включает проверку токена.
- CORS middleware не подключён. Для локальной разработки настройте dev-proxy и один origin; междоменные запросы нужно согласовать с gateway/backend. Заголовки CORS сервис сейчас не обещает.
- Аутентификация не означает авторизацию. Проверки прав пользователя и интеграция AuthZ/SpiceDB пока не реализованы. Каталог `/permissions` не является списком разрешённых пользователю действий.
- Outbox фиксирует события в БД, но публикация и доставка прав во внешнюю систему ещё не подключены. Успешное назначение означает запись в roles-service.
- Пользователи и ресурсы scope внешние. Сервис не возвращает их имена и не подтверждает их существование через другие сервисы.
- Шаблон заполняет форму. Нет endpoint для автоматического развёртывания шаблона или распространения его изменений на роли.
- PATCH, массовые назначения, cursor-пагинация и получение эффективных прав не предусмотрены текущим контрактом.
- `version` и `total` имеют OpenAPI-тип int64. Контракт не ограничивает их диапазоном безопасных целых JavaScript; для значений выше `Number.MAX_SAFE_INTEGER` нужна согласованная стратегия точного разбора JSON, а не `BigInt` после обычного `JSON.parse`.

OpenAPI и миграции при текущем архитектурном рефакторинге не менялись.
